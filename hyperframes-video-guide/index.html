你必须知道

编辑者要做的判断

  • 这条片子的目标：种草、解释、复盘、发布、引流、讲故事。
  • 整体气质：温柔、高级、数据感、科技感、强冲击、电影感。
  • 哪里是重点：开头抓人、某个金句、某个数字、某个证据截图。
  • 不要什么：不要太花、不要遮脸、不要像 PPT、不要太赛博。
  • 你喜欢的参考：可以说“像第几张风格卡”或“像液态玻璃那张”。
交给 AI

让 Codex / Claude Code 自己做

  • 查官方素材库，找出可用的素材模块和转场。
  • 决定具体素材名，比如用 flowchart、data-chart 还是 x-post。
  • 安装和接入素材，也就是运行 hyperframes add 和写入页面。
  • 安排素材出现的时间、大小、位置、层级和持续时间。
  • 预览后根据画面拥挤程度，删掉不必要的效果。

常见视频怎么搭

不同视频类型，可以这样组合

HyperFrames 提供的是可调用的素材和效果，不会替你决定整条片子怎么剪。下面这些组合是我按素材用途和常见视频场景，翻译成更像剪辑沟通的话。

口播 / 个人故事

温柔但不无聊

  • 风格：Soft Signal
  • 字幕：慢慢淡入，或按词高亮
  • 转场：光轻轻扫过，或热浪一样柔和扭曲
  • 可用素材：胶片颗粒、纹理文字

一句话：像温柔手帐页，但每屏都有轻微漂浮和重点划线。

教程 / 方法论

清楚、可信、好跟上

  • 风格：Swiss Pulse
  • 字幕：教程感字幕，或打字机出现
  • 转场：推到下一页，或用圆形镜头孔揭晓
  • 可用素材：流程图、动态图表

一句话：用流程图和数字引导观众，不要让装饰抢走步骤。

AI / 科技趋势

未来感和信息密度

  • 风格：Data Drift
  • 字幕：干净、克制、信息清楚
  • 转场：空间扭曲、画面像被吸进去
  • 可用素材：流体背景、光标文字揭晓

一句话：深色、粒子、漂移线条，但文字必须少而清楚。

开头抓人 / 爆点

先抓住眼睛

  • 风格：Maximalist Type
  • 字幕：大字弹出，关键词放大
  • 转场：燃烧撕裂，或数字故障闪动
  • 可用素材：金额跳数、彩色冲击转场

一句话：前三秒用大字和强节奏，后面要收回清晰解释。

产品 / App 展示

像产品广告

  • 风格：Velvet Standard 或 Swiss Pulse
  • 字幕：干净、像发布会字幕
  • 转场：电影感推进，或水一样揉过去
  • 可用素材：3D 手机电脑、界面 3D 展示、App 展示

一句话：截图不要平铺，尽量做成手机/电脑里的动态界面。

悬疑 / 揭露 / 风险

压暗、慢推、强揭晓

  • 风格：Shadow Cut
  • 字幕：少字、强对比
  • 转场：空间扭曲，或电影感推进
  • 可用素材：X 帖子、Reddit 帖子、电脑通知弹窗

一句话：让证据卡片从黑暗里出来，少用可爱动效。

一句话总结

HyperFrames 对你来说不是“写代码工具”，而是一个让 Codex 或 Claude Code 调用更丰富画面效果的视频素材系统。你的关键能力不是会写 HTML，而是会说清楚：整体风格、重点动效、素材模块、转场方式。
