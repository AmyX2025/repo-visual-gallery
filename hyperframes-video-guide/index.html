指挥 Agent用 HyperFrames剪出好视频

这份指南解决的不是“怎么导出一个 MP4”，而是： 怎样让 Codex、Claude Code 或未来的 Agent 先看懂能力库，再用更少返工做出更高级、更贴合口播的视频。

阅读方式： 先看完整工作流和确认关卡，再看风格、字幕、动效、转场和素材模块，最后用“需求模板”生成一段可以直接发给 Agent 的剪辑要求。

这份指南 把工作流、能力库和提示词收在一起，避免 Agent 新开 session 后凭感觉乱剪。

三个常用词

素材模块 = 像剪映里的现成模板片段。

转场 = 两个画面之间怎么换过去。

高级转场 = 普通推拉之外，更有视觉冲击的切换效果。

核心目标 优质，不只是能出片

重点不是让 Agent 导出视频，而是让它理解内容、查清能力、做出可判断的视觉方案，再进入完整制作。

能力索引 先知道有什么子弹

新 session 不能假设 Agent 自动知道全部 blocks、转场、字幕和风格。开工前要先让它读文档、查库、给你选项。

确认方式 视觉判断要可视化

只用文字说“这里用悬浮卡片”不够。真正要确认的是 HTML storyboard、关键帧或 10-20 秒短样片。

先把合作方式定清楚

完整工作流：谁做什么，谁确认

这不是只为了节省渲染时间。真正浪费时间的是确认点放得太晚：内容没对齐就做动效，视觉没看过就做全片，最后只能大返工。

形态 A

HTML / PPT 主画面 + 真人 PIP

主画面承载图解、页面、流程和观点，真人作为右侧或右下角小窗出现。适合横屏课程、复杂概念解释、方法论和 Agent 工作流。

形态 B

真人主画面 + 动态信息层

真人是主画面，信息层只负责加强重点、证据、截图、定义和趋势。适合小红书竖屏口播，不能做成廉价贴纸堆叠。

1
Agent 先做

素材识别

扫描待剪辑文件夹，判断哪个是口播视频、口播稿、截图证据、参考图、可复用素材。

具体动作
  • 列素材，不直接删除或移动。
  • 如果有多个口播视频，按时长、大小、修改时间判断。
  • 新建独立项目目录，避免中间产物乱堆。
Amy 确认点

只在素材有歧义时需要你确认。素材明确时，Agent 可以继续往下跑。

2
Agent 先做

ASR 时间轴

对真实口播视频转文字，拿到每句话的时间。ASR 是时间依据，口播稿只是理解依据。

具体动作
  • 用中文 ASR 生成 JSON / SRT。
  • 找出开头、转折、证据、金句、结尾的真实时间点。
  • 不靠文稿平均分配时间。
Amy 确认点

通常不需要你确认技术结果，但如果 ASR 错得离谱，Agent 要先指出问题，不能继续硬做。

3
必须确认

页面 / 信息层规划

先决定每个时间段画面上出现什么。屏幕文字不是字幕，而是帮观众记住重点。

Agent 输出
  • 时间段 / 口播内容 / 观众要记住什么。
  • 屏幕文字 / 用哪个素材 / 动效备注。
  • 哪些地方放证据截图，哪些地方只留给口播。
Amy 确认点

确认“这里到底该展示什么”。这一步不通过，后面做得再漂亮也可能偏题。

4
必须可视化

视觉样板

涉及风格、悬浮卡、字幕、转场、证据截图展示方式时，不能只用文字描述。

Agent 输出
  • HTML storyboard 或关键帧页面。
  • 必要时做 10-20 秒短动效样片。
  • 对比 2-3 个视觉方向，不要全片先做完。
Amy 确认点

你看画面判断：高级吗？像贴纸吗？遮脸吗？字幕抢不抢？证据截图看得清吗？

5
Agent 先做

完整制作

确认内容和视觉方向后，再写 HyperFrames HTML、CSS、GSAP，接入 blocks、字幕、转场和素材。

具体动作
  • 按 ASR 锚点安排画面出现和退出。
  • 先本地预览、检查遮挡和文字溢出。
  • 跑 lint / inspect / validate，先排低级问题。
Amy 确认点

一般看局部预览或样片即可。不要每改一点就要求完整出片。

6
最终确认

成片 QA

完整渲染只是其中一步，关键是检查最终 MP4 里画面和口播是否真的对齐。

Agent 输出
  • 完整 review / final MP4。
  • 关键时间点抽帧 contact sheet。
  • 问题清单：遮挡、错位、空帧、字幕区、截图清晰度。
Amy 确认点

你主要判断整体节奏、审美、观点是否被正确突出。技术问题应该由 Agent 先自查。

7
Agent 收尾

归档和回写

每跑通一条片子，都要把新规则写回项目文档。这样下一个 Agent 才能继承经验。

具体动作
  • 保留最终成片、ASR、源码、规划表、QA 图。
  • 更新 PROJECT_STATE、设计说明和复用规则。
  • 稳定经验再回写 skill / 第二大脑 / GitHub 手册。
Amy 确认点

如果要删除中间产物或改长期规则，先给你看清单，确认后再执行。

视觉确认不是口头描述

凡是影响审美的选择，都要先变成可看的东西

如果 Agent 只写“这里用悬浮卡片、这里用高级转场”，你还是在开盲盒。正确做法是先给你可看的 HTML 或短样片。

信息层规划表确认每个时间点画面上到底出现什么，不先讨论颜色和花活。
HTML storyboard把几屏关键画面做成可滚动页面，让你直接看布局和层级。
关键帧对比颜色、字体、卡片大小、人物位置、截图展示方式可以并排比。
10-20 秒短样片用来判断节奏、动效和转场，不等整条片子做完才发现不对。

先定整体气质

8 种画面风格，先看气质再选

这些来自 HyperFrames 的风格库。你主要看中文解释和小样；英文名只是给 Codex 或 Claude Code 下指令时更稳定的“引用名”。

看文字怎么动

动效不是装饰，是语气

同一句话，用“弹出来”“慢慢浮现”“打字机出现”“荧光笔划过”，观众感受到的情绪完全不同。这里按剪辑语言理解就够了。

中文字幕怎么长

字幕不是翻译条，是节奏和重点

HyperFrames 可以把中文字幕直接烧录进 MP4。它没有剪映式模板按钮，但可以用 HTML/CSS/GSAP 做出下面这些字幕语言：底部字幕、逐词高亮、荧光笔、弹跳、打字机、片名卡。

真实制作时，我会先用中文 ASR 拿时间轴，再把逐字稿整理成更适合上屏的短句。字幕不能遮脸，也不能遮右下角口播小窗。

看镜头怎么切

转场用来表达段落关系

温柔内容别乱用故障闪动；高能发布也不要慢慢融化。转场不是越花越好，而是帮观众理解“这里发生了什么变化”。

你必须知道

编辑者要做的判断

  • 视频形态：主画面是 HTML/PPT，还是真人口播。
  • 这条片子的目标：种草、解释、复盘、发布、引流、讲故事。
  • 整体气质：温柔、高级、数据感、科技感、强冲击、电影感。
  • 哪里是重点：开头抓人、某个金句、某个数字、某个证据截图。
  • 不要什么：不要太花、不要遮脸、不要像 PPT、不要太赛博。
  • 视觉样板是否通过：高级吗、清楚吗、像不像廉价贴纸。
交给 AI

让 Codex / Claude Code 自己做

  • 查官方素材库，找出可用的素材模块和转场。
  • 决定具体素材名，比如用 flowchart、data-chart 还是 x-post。
  • 安装和接入素材，也就是运行 hyperframes add 和写入页面。

完整素材库怎么用

不会素材名也可以调用

你可以直接要求：“我不知道具体素材名，请先查 HyperFrames 官方素材库，按我的内容推荐 3 个可用素材，并解释为什么。”

调用前先让它解释

不要让 Agent 直接乱塞效果

常见视频怎么搭

不同视频类型，可以这样组合

HyperFrames 提供的是可调用的素材和效果，不会替你决定整条片子怎么剪。下面这些组合是我按素材用途和常见视频场景，翻译成更像剪辑沟通的话。

口播 / 个人故事

温柔但不无聊

  • 风格：Soft Signal
  • 字幕：慢慢淡入，或按词高亮
  • 转场：光轻轻扫过，或热浪一样柔和扭曲
  • 可用素材：胶片颗粒、纹理文字

一句话：像温柔手帐页，但每屏都有轻微漂浮和重点划线。

教程 / 方法论

清楚、可信、好跟上

  • 风格：Swiss Pulse
  • 字幕：教程感字幕，或打字机出现
  • 转场：推到下一页，或用圆形镜头孔揭晓
  • 可用素材：流程图、动态图表

一句话：用流程图和数字引导观众，不要让装饰抢走步骤。

AI / 科技趋势

未来感和信息密度

  • 风格：Data Drift
  • 字幕：干净、克制、信息清楚
  • 转场：空间扭曲、画面像被吸进去
  • 可用素材：流体背景、光标文字揭晓

一句话：深色、粒子、漂移线条，但文字必须少而清楚。

开头抓人 / 爆点

先抓住眼睛

  • 风格：Maximalist Type
  • 字幕：大字弹出，关键词放大
  • 转场：燃烧撕裂，或数字故障闪动
  • 可用素材：金额跳数、彩色冲击转场

一句话：前三秒用大字和强节奏，后面要收回清晰解释。

产品 / App 展示

像产品广告

  • 风格：Velvet Standard 或 Swiss Pulse
  • 字幕：干净、像发布会字幕
  • 转场：电影感推进，或水一样揉过去
  • 可用素材：3D 手机电脑、界面 3D 展示、App 展示

一句话：截图不要平铺，尽量做成手机/电脑里的动态界面。

悬疑 / 揭露 / 风险

压暗、慢推、强揭晓

  • 风格：Shadow Cut
  • 字幕：少字、强对比
  • 转场：空间扭曲，或电影感推进
  • 可用素材：X 帖子、Reddit 帖子、电脑通知弹窗

一句话：让证据卡片从黑暗里出来，少用可爱动效。

练习怎么选

用场景反推选择

你不需要背概念。真实剪辑里只要能说：“这条片子像哪张卡？我要哪种动感？这里插哪个素材模块？”就够用了。

一句话总结

HyperFrames 对你来说不是“写代码工具”，而是一个让 Codex、Claude Code 或未来 Agent 调用更丰富画面效果的视频生产系统。你的关键能力不是会写 HTML，而是会设定目标、确认信息层、要求可视化样板，并在 Agent 查清能力库后做审美取舍。
